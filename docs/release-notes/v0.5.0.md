## <a id="english"></a>English

Installer: `SAS-Launcher-0.5.0-x64-Setup.exe`

### Install

1. Quit the launcher and close every SAS session first: saving user settings needs exclusive access to `My SAS Files`, and a running SAS blocks it.
2. Run the installer over the existing folder; it upgrades in place, with no uninstall step.
3. Projects, configurations and session logs stay in `%LOCALAPPDATA%\com.saslauncher.desktop\v4`; the installer never clears them.

Rolling back: before reinstalling v0.4.0, switch the interface language to "Follow System", Simplified Chinese, Traditional Chinese or English — the five languages added in 0.5.0 do not exist in 0.4.0, so its settings page reports `settingsRead`; reinstalling 0.5.0 and picking a language the older version knows clears it. The `v4` data is unchanged and the older version reads it.

### Added

- A session card on the diagnostics page now opens the log's ERROR and WARNING lines: listed in line order, continuation lines folded back into one, and the copy button carrying the `sas.log:NNN` locator.
- Five interface languages join the app — Japanese, Korean, German, Spanish and French — for eight in total.

### Improved

- The card's "Open log" button is now "Open full log", so it is no longer confused with the per-line list.

### Other changes

- The shared interface copy is one row per language now: endonym, date format, list separator and collation sit together instead of drifting across files.
- The READMEs gain Japanese, Korean, German, French and Spanish, for eight in total; their structure, switcher and relative links are guarded by `npm run check`.
- Tests lock the UI colour tokens' contrast and the no-inline-style rule, so neither can silently break under the packaged CSP.
- `docs/i18n.md` records the eight languages and the README contract, and gains the manual acceptance checklist for a release.

### Known limitations

- A Windows display-language change needs a sign-out, and the app picks the new language up on its next start.
- The installer's language choice only affects the installation, not the app language.
- A configuration keeps the name it was created with; switching the interface language does not rename it.
- Diagnostics read only the first 2000 entries or 8 MiB of a log and say so in the card.

> [!IMPORTANT]
> This installer is unsigned. Windows SmartScreen will warn when you run it: choose "More info" and then "Run anyway" only if you trust this build.
