## <a id="english"></a>English

Installer: `SAS-Launcher-0.3.0-x64-Setup.exe`

### Install

1. Quit the launcher and close every SAS session first: saving user settings needs exclusive access to `My SAS Files`, and a running SAS blocks it (a failure now says so on the spot).
2. Run the installer over the existing folder; it upgrades in place, with no uninstall step.
3. Projects, configurations and session logs stay in `%LOCALAPPDATA%\com.saslauncher.desktop\v4`; the installer never clears them.

Rolling back: reinstall the v0.2.0 installer; the `v4` data written by 0.3.0 still reads there (it only ignores the new per-session preference list).

### In this release

- A project's user settings now carry Environment by default: library assignments, the Explorer view and print setup travel with the session instead of starting from the default icon view.
- Settings are taken back when the session exits, even when the exit code is unknown, so closing the SAS window no longer loses what was just tuned.
- Batch launches now read the same project settings as single ones; they used to ignore the project's own choice.
- A failed save is no longer silent: the reason appears inside the card being edited, with a Retry button.
- Diagnostics gained a Preference row naming the settings groups and the file count a session actually received.
- Copy clean-up: no more internal words such as "layer" or "snapshot"; an empty folder, a missing file and an unsaved configuration each say their own thing.

### Known limitations

- Existing projects do not gain Environment by themselves; tick it once and save. This release changes nothing you did not ask for.
- The Enhanced Editor's font, colours and key bindings live in the Windows registry and cannot be isolated or saved.
- Data from versions before 0.2 is not migrated: the old folder is archived to `_old-<date>`.

> [!IMPORTANT]
> This installer is unsigned. Windows SmartScreen will warn when you run it: choose "More info" and then "Run anyway" only if you trust this build.
